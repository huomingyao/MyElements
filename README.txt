元素炼金物语 vH20-MVP

【运行】双击 ElementAlchemy.exe，无需安装 Godot。

【操作】
  A/D 或 ←/→  移动        Space  跳跃
  E  交互/合成台（靠近时）  Tab  背包
  C  图鉴                 M  世界地图
  1–8  快捷栏使用         Esc  暂停/收起面板

【导师联网】
  首次运行会在存档目录生成 config.cfg，填入 DeepSeek API key 后
  导师会走在线回答；未填或断网时自动使用离线知识库，
  回答带「（离线模式）」标记，全部流程仍可完整体验。
