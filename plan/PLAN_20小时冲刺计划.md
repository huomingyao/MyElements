# 《元素炼金物语》比赛 MVP — 20 小时冲刺计划

> 本文件是「plan + spec 文档集」的计划部分。
> 阅读顺序：**本计划 → SPEC_游戏设计规格 → SPEC_技术与数据规格 → SPEC_内容数据表**。
> 计划管"谁在什么时间交出什么"，三份 spec 管"做出来的东西长什么样"。

---

## 1. 阶段定位与四条铁律

**目标**：20 小时后交出两样东西——
1. 评委能上手玩 10~15 分钟的 **Windows 可玩 demo**（完整闭环，断网可玩）；
2. 一支 **3 分钟演示视频**（防现场设备翻车的备份，也是评分材料）。

**四条铁律**（任何人任何时刻不得违反）：

| # | 铁律 | 原因 |
|---|------|------|
| 1 | 只做"评委 10 分钟能玩懂的闭环"，其余一切进赛后清单 | 20 小时装不下完整设计文档 |
| 2 | 断网必须可玩（LLM 有本地兜底问答） | 比赛现场网络不可控 |
| 3 | 每个整点可构建、可运行，git 不许留"明天再合"的代码 | 5 人并行，最后一刻合并 = 爆炸 |
| 4 | 改文案不改代码——物质、配方、字幕、导师人设全部数据表驱动 | 内容调整是最后 5 小时的主要工作 |

**功能冻结时间**：H12（第 12 小时末）。之后只修 bug、填内容、调数值，不加任何新功能。
**砍功能裁决人**：P1（一人说了算，避免讨论耗时间）。

## 2. MVP 范围（一句话）

> 草原收集 → 营地合成 → 氢气爆炸 → 导师问答 → 夜晚生存 → 睡觉复活，
> 10~15 分钟闭环；地图 = 草原 + 营地 + 盐湖 + 矿洞一层 + 导师学院。

### 做 / 不做

| 做（MVP） | 不做（赛后清单，谁提谁记录，不讨论） |
|---|---|
| 三值系统（氧气/能量/生命） | 自由建造/放置方块 |
| 昼夜循环（白天采集、夜晚怪物、床睡觉跳过） | 存档/读档 |
| 采集 + 背包（16 种物质） | 深层矿洞、火山口等未解锁区域的实装 |
| **盐湖区域**（安全收集区：粗盐提纯 + 硬水） | 未解锁区域内部场景的任何制作 |
| **世界地图页**（13 区域全展示，8 个灰色剪影未解锁） | 区域间传送（未解锁区域点不开即可） |
| 合成台 + 10 条反应配方 + 知识卡片弹窗 | 铁锈虫（第 3 种怪） |
| **氢气不验纯爆炸事件**（全场核心记忆点） | 导师性格滑块实装（UI 可做占位） |
| 怪物 ×2（CO 幽灵、酸雾怪） | 化肥农田、溶解度、技能树 UI |
| 导师学院：4 位具名 AI 导师（**房间内像素小人 + 底部聊天框 + 班主任统一调度机制**，LLM API + 本地兜底） | 溶解度曲线、配平校验等进阶玩法 |
| 图鉴简版（收集进度网格 + 卡片） | 联机、原创音乐 |
| 死亡 → 床铺复活 + 死亡掉落可捡回 | 多语言、手柄支持 |
| 字幕引擎（约 30 条知识点字幕） | |
| 主菜单（三个门：开始冒险/导师学院/图鉴） | |

## 3. 五人分工（AI 辅助贯穿全程）

> 原则：AI（Claude Code / Kimi / DeepSeek）写代码初稿，人负责提需求、整合、验收。
> 每人一个"责任目录"，合并冲突最小化（目录划分见技术 spec 第 2 节）。

| 角色 | 责任人 | 负责内容 | 交付物 |
|---|---|---|---|
| **P1 主程/架构** | 编程最强者 | Godot 项目骨架、玩家控制器、相机、三值系统、昼夜循环、主菜单、构建导出、功能冻结裁决 | 可运行主干 + Windows exe |
| **P2 玩法程序** | 次之 | 采集/背包、配方引擎、合成台交互、知识卡片弹窗、怪物 AI×2、氢气爆炸事件、死亡/复活/掉落 | 全部玩法机制 |
| **P3 AI 与内容** | 文字能力强者 | 导师系统（LLM 接入 + 路由 + 本地兜底）、字幕引擎、全部文案（tips/卡片/知识库/兜底 QA） | 导师聊天可用 + 内容数据表填完 |
| **P4 美术** | 有审美者 | Image-2 网页生成素材（含**4 位导师半身立绘 idle/talk×8**，提示词已备好在内容 spec 第 4 节）、免费素材包筛选（含导师房间像素小人改色）、切片/导入、UI 界面（含世界地图页底图）、调色板统一终审 | 全部可见的美术资产 |
| **P5 整合/QA/视频** | 细心者 | 地图 TileMap 搭建（P1 出白盒后接美化）、测试清单执行、bug 台账、演示视频录制剪辑、PPT/讲稿 | 测试报告 + 3 分钟视频 + PPT |

**结对安排**：P1 带 P2（代码互相 review），P3 的内容表由 P5 帮忙录入（H8 后 P5 主要转入测试和视频）。

## 4. 时刻表（H0 = 现在，共 20 小时）

> 每个整点：git push + 本地构建一次，确认能跑。构建挂了优先修构建。

### 第一阶段：启动与底座（H0–H4）

| 时段 | 全员动作 |
|---|---|
| H0–H1 | 启动会 30 分钟对齐本文档；建 git 仓库与分支规范；P1 建 Godot 空项目并推到仓库；**P4 立刻发出 Image-2 第一批生成提示词**（网页生成要排队：主角×2 + 标题图 + 导师立绘 idle/talk×8，提示词已备好在内容 spec 第 4 节与技术 spec 第 7 节） |
| H1–H2 | P1：玩家控制器（移动/跳跃/交互键）+ 相机 + 白盒地图；P2：背包数据结构 + 采集交互原型；P3：字幕引擎 Autoload + tips.json 框架；P4：筛选免费像素素材包（地形/UI 打底）；P5：画地图白盒布局（三区 + 学院位置关系） |
| H2–H4 | P1：三值系统 + HUD + 昼夜循环（画面 tint 变暗即可）；P2：配方引擎（读 recipes.json）+ 合成台交互；P3：导师聊天 UI + LLMClient 联通 DeepSeek API（先发通第一条消息）；P4：处理第一批生成图（去背景/缩放到像素规格/统一调色）；P5：TileMap 铺草原和营地 |

**H4 检查点**：玩家能在白盒地图上跑、捡东西、打开合成台合成出硫火把（无美术也行）。

### 第二阶段：核心闭环（H4–H12）

| 时段 | 全员动作 |
|---|---|
| H4–H6 | P1：氧气分区消耗（草原慢/矿洞快）+ 电解器剧情点（得 H₂/O₂）+ **世界地图页**（13 区域底图 + 热区）；P2：知识卡片弹窗 + CO 幽灵 AI；P3：4 位导师 system prompt 调通 + 自动路由（关键词分发）；P4：矿洞/盐湖素材 + 怪物素材 + 地图页底图；P5：铺矿洞和盐湖 + 开始搭测试清单 |
| H6–H8 | P1：床（睡觉跳过夜晚）+ 主菜单三个门；P2：**氢气爆炸事件**（未验纯点燃 → 爆炸动画 → 扣血 → 引导字幕）+ 酸雾怪；P3：本地兜底 QA（qa_fallback.json）+ 断网切换开关 + **底部聊天框 UI**；P4：爆炸动画 + 知识卡片 UI 美化 + 导师小人切片导入；P5：铺导师学院（四房间摆导师小人）+ 录屏测试素材备用 |
| H8–H10 | P1：死亡/复活/掉落；P2：中和喷雾/活性炭口罩/灭火器道具生效；P3：填字幕与卡片文案（对照内容数据表 spec）；P4：导师头像（两帧张合动画）+ 图鉴 UI；P5：第一轮全流程跑通测试，开 bug 台账 |
| H10–H12 | 全员：整合联调。P3/P5 填图鉴文案；P1 修阻塞性 bug；**H12 末：功能冻结** |

**H8 检查点**：爆炸事件 + 导师问答（联网）跑通——这是演示的高潮，优先级最高。
**H12 检查点（冻结点）**：完整闭环可以从头到尾玩一遍，允许丑、允许有小 bug，不允许缺环节。

### 第三阶段：打磨与交付（H12–H20）

| 时段 | 全员动作 |
|---|---|
| H12–H14 | 数值调参（氧气消耗速率/怪物伤害/昼夜时长，目标：评委 10 分钟体验到全部环节）；bug bash 第一轮 |
| H14–H16 | P4 美术终审统一；P3 文案终审；P1 导出 Windows exe；**P5 做断网测试（拔网线跑全流程，验证本地兜底）** |
| H16–H18 | P5 按脚本录制演示视频 + 剪辑；P3 写 PPT/讲稿；其余人第二轮 bug bash + 彩排演示路径（每人照"演示路径"玩两遍） |
| H18–H19 | 最终打包：exe + 视频 + PPT 拷入 U 盘 ×2 + 云盘备份；演示机环境确认 |
| H19–H20 | **缓冲**。什么都不加。累了轮流睡。 |

## 5. 风险与对策

| 风险 | 概率 | 对策 |
|---|---|---|
| 现场断网，导师变哑巴 | 高 | 本地兜底 QA（≥20 条关键词问答）+ H16 断网全流程测试；演示话术准备"离线模式也能答" |
| DeepSeek API 额度/key 失效 | 中 | 准备 2 个 API key；P3 写好"一键切换离线模式"开关；手机热点备用 |
| 5 人合并冲突 | 高 | 责任目录制（技术 spec 第 2 节）；整点 push；P1 统一合并 |
| 素材风格不统一 | 中 | 全项目一套调色板 + 固定像素规格（16×16 道具 / 32×32 角色）；P4 一人终审，不统一就压调色板重导 |
| 范围蔓延（"要不加个 XX"） | 极高 | 一律记进赛后清单；P1 有砍功能独裁权；H12 后只修不加 |
| 初学者卡壳阻塞 | 中 | 结对（P1↔P2）；卡住 30 分钟必须喊人；AI 辅助先出原型再改 |
| 演示视频来不及 | 低 | H6 起 P5 随手录屏存素材；视频脚本在 spec 里已写好，照拍即可 |

## 6. 验收清单（Definition of Done，H18 逐条打勾）

- [ ] 主菜单三个门可进，开始冒险能进入世界
- [ ] 出生草原，能捡到 O₂、C，头顶出现知识字幕，左上角计数 2/16
- [ ] 盐湖能捡粗盐、对湖水用肥皂水出现硬水字幕；回营地可完成粗盐提纯得到 NaCl
- [ ] 世界地图页打开能看到 13 个区域：5 个彩色可点，8 个灰色剪影 + 预告文案 +「赛后解锁」
- [ ] 氧气值随时间下降，进矿洞下降明显加快，HUD 可见
- [ ] 营地过滤器交互触发净水四步字幕；电解器触发电解剧情并获得 H₂
- [ ] 合成台能用 木棒+S 合成硫火把，弹出知识卡片（方程式 + 现象词）
- [ ] H₂ + O₂ 未验纯点燃 → 爆炸动画 + 扣血 + 引导去导师学院的字幕
- [ ] 导师学院四个房间各有导师像素小人；走近按 E 弹出底部聊天框
- [ ] 提问"为什么氢气会爆炸"：班主任苏婉清首接并 @化学老师，袁仲衡回答（含配平方程式），答完即终止不再跳转（联网 LLM 与离线兜底各测一遍）
- [ ] 夜晚到来，酸雾怪出现，中和喷雾可消灭；CO 幽灵旁戴活性炭口罩不掉血
- [ ] 床可睡觉跳过夜晚；死亡后床铺复活、物品掉在死亡点可捡回
- [ ] 图鉴打开能看到收集进度与已解锁卡片
- [ ] **拔网线全流程重玩一遍，无任何卡死/报错**
- [ ] exe 拷到一台没装过 Godot 的电脑上能直接运行
