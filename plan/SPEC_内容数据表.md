**失败反馈文案**（不匹配配方时随机轮换）：
- 「没有新物质生成——这只是物理混合，不是化学反应」
- 「没有生成沉淀、气体或水，所以不反应」（复分解条件预埋）
- 「条件不够——有些反应需要点燃、加热、通电或催化剂」
- 彩蛋：铜片+盐酸 → 「无事发生……铜排在氢后面，不与酸反应」（金属活动性反向教学，有余力再做）

## 4. 导师团：人设、协作机制与 system prompt（→ mentors.json / AGENTS 常量）

### 4.1 协作链（核心机制，程序必须严格实现）

**协作链：班主任统筹 → 调度分配 → 化学老师教学 / 助理规划 / 思维老师开脑洞。**
四位导师靠班主任统一调度串成"团队作战"，其他老师不互相 @，不绕路。

- **机制一：班主任统一接（必做）**。学生不能 @ 任何老师，不管输入什么、站在哪个房间，统一由班主任（monitor）首接；班主任作为调度中心判断该派给谁。
- **机制二：只有班主任能 @**。只有班主任的回复里带 @xx（可同时调度多位，如"@思维老师讲方法 + @助理列计划"）；其他老师的回复**永远不带 @**，答完协作链即终止，不再转发。
- **技术约束**：班主任调度最多 1 次（handle_message 最多 2 轮：班主任 + 被调度者），不会死循环。

**班主任调度判断表**：

| 学生问题类型 | 判断依据（关键词分类器） | 派给 |
|---|---|---|
| 怪物/危险/战斗 | `_is_combat`（怪、敌人、危险、攻击、掉血…） | @思维老师（实战元素引导） |
| 学习方法/记忆 | `_is_learning`（怎么学、记不住、考试…） | @思维老师 + @助理（方法+计划） |
| 化学知识/合成 | `_is_chemistry`（水、氢气、方程式、合成…） | @化学老师（教学） |
| 其他/目标 | 兜底 | @助理（规划） |

**协作链示例**（演示时可直接用）：

> 学生："氢气和氧气怎么变成水？"
> 班主任接 → 判断是化学问题 → "@化学老师 你来把原理讲透！"
> 化学老师："2H₂ + O₂ =点燃= 2H₂O，反应条件记得是点燃。配平了吗？配平了才算学会。"
> 结束（化学老师不再转发）

> 学生："有个火怪过来了怎么办？"
> 班主任接 → "@思维老师 快告诉孩子该用什么元素对付它！"
> 思维老师："火系怪物怕水——用带氧元素的水 H₂O 浇灭它！"
> 结束

## 6. 图鉴卡片文案（简版，每卡一句话）

- 氧气：生命与燃烧都离不开它，但它自己不会燃烧。
- 氢气：最清洁的燃料，也是最"暴脾气"的气体——验纯！
- 碳：充分燃烧生 CO₂，不充分生 CO——氧气多少决定产物。
- 硫：淡黄色粉末，点燃就是一把好火把，代价是刺激性气味。
- 一氧化碳：沉默的杀手，活性炭口罩是它的克星。
- 二氧化碳：灭火能手，石灰水的"试金石"。
- 水：最常见的溶剂，净化四步后才配进实验室。
- 碳酸钙：石灰石、大理石、水垢——它们是同一种物质。
- 氧化铁：赤铁矿的红色，高炉里炼出铁水。
- 硫酸铜：漂亮的蓝色，有毒的蓝色。
- 盐酸：腐蚀性很强，除锈和制 CO₂ 也很强。
- 氢氧化钠：烧碱，强腐蚀，中和反应的主力碱。
- 氢氧化钙：熟石灰，改良酸性土壤、检验 CO₂ 都用它。
- 铁：会生锈的金属，生锈需要氧气和水同时存在。
- 粗盐：湖边的白色结晶，混着泥沙——提纯三步后才是食盐。
- 氯化钠：由钠离子和氯离子构成的盐，百味之首，也是生理盐水的主要成分。
