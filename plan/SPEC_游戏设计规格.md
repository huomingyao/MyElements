# SPEC｜《元素炼金物语》游戏设计规格（MVP 版）

> 本文件定义"玩起来是什么样"。所有内容以 **MVP（20 小时比赛版）** 为准；
> 完整版（12 单元、6+ 区域）的设想只在第 8 节列出，不在本次实现范围。

---

## 1. 产品概念

**一句话**：一个 2D 横版像素开放世界，世界规则就是初中化学课本——没有魔法，只有化学。

玩家是一个小炼金术士，在一张持续存在的世界里收集真实物质、用真实反应条件合成道具、靠化学知识活下去（照明、防毒、灭火、打怪），遇到不懂的就去地图中央的「导师学院」问四位 AI 导师。

**三句收束文案**（对外统一口径，视频结尾和 PPT 都用它）：
- 对玩家：这是一个不作弊就玩不下去的游戏——而作弊方式恰好是翻开化学书。
- 对家长：他玩的每一次合成，都是考卷上要写的那条方程式。
- 对评委：我们把初中化学翻译成了游戏机制——知识不是游戏的皮肤，是游戏的物理引擎。

---

## 2. 核心循环

```
探索收集 → 鉴别/合成 → 用品生存 → 卡关问导师 → 学到知识 → 更深探索
     ↑                                                        │
     └──────── 三值永远下降 + 怪物每晚刷新 = 循环永远转 ────────┘
```

**永续发动机（区别于剧情 demo 的关键）**：唯一失败 = 死亡（床铺复活、掉落可捡回）；没有通关，玩家目标自定（集齐图鉴 15 种？挖穿矿洞？）。资源可再生：树和矿脉在每天清晨刷新，世界采不空。

---

## 3. 世界与地图（MVP：4 区 + 1 学院，一张连续地图不切场景）

```
[盐湖]——[矿洞一层]                [导师学院]
           │ 入口在草原右侧         │ 地图中央偏上，安全区
        [草原（出生点）]——[营地]—————┘
        （草原与营地相连，营地是草原的一部分；盐湖在草原左侧，无怪物）
```

| 区域 | 可收集物质 | 环境机制 | 覆盖知识点 |
|---|---|---|---|
| **草原**（出生） | O₂（光球）、C（木炭）、树木 | 氧气消耗慢；白天安全 | 空气成分、光合作用、物理/化学变化 |
| **营地**（草原内） | 水（河边取水）、H₂（电解器） | 固定设施：过滤器、电解器、合成台、篝火、床 | 水的净化四步、电解水、六大营养素 |
| **盐湖**（新增·安全区） | 粗盐（含 NaCl 的结晶）、湖水（硬水） | 无怪物无消耗，纯收集+教学区；湖水不可直接饮用/实验 | 粗盐提纯（溶解→过滤→蒸发）、硬水与软水、溶解现象 |
| **矿洞一层** | S、CaCO₃、CuSO₄（溶液池）、Fe₂O₃ | 氧气消耗 ×4；黑暗需火把；CO 幽灵出没 | 燃烧条件、CO 毒性、矿物成分 |
| **导师学院**（安全区） | 无收集 | 四导师常驻（像素小人实体）；怪物不入内；无消耗 | 全部知识兜底问答 |

**盐湖设计说明**（为什么加它）：机制最简单（无怪物、无数值威胁），半小时就能铺完，但让地图从"一条线"变成"有左右探索感"，并且顺手覆盖第 11 单元「盐 化肥」的粗盐提纯和硬水考点。玩法：湖边捡粗盐 → 回营地实验台三步提纯（溶解→过滤→蒸发，分步字幕）→ 得到 NaCl；对湖水使用肥皂水道具 → 字幕「硬水遇肥皂水不起沫」。

**区域字幕**（走近触发一次）：草原「空气：氮气 78%、氧气 21%」；盐湖「盐湖的湖水又苦又涩——这是硬水，含较多钙镁离子」；矿洞「矿洞氧气稀薄——氧气只占空气的 21%」；河边「天然水含杂质，需净化后才能用于实验」。

### 3.1 世界地图页（关键展示点：全部区域可见，未解锁的为剪影）

- 入口：主菜单一个门 + 游戏内按 M / 点营地路牌打开。
- 形态：手绘风世界地图，**13 个区域全部显示在页面上**——已解锁的 5 个为彩色 + 可点击查看简介；未解锁的 8 个为**灰色剪影 + 名称 + 一句预告文案 +「赛后解锁」标签**（完整区域清单与预告文案见内容数据表 spec 第 7 节）。
- 未解锁区域：深层矿洞、火山口·熔炉高地、金属矿山、酸碱沼泽、水晶矿洞、气之国、生命草原、电解实验室。
- 设计意图：评委打开地图一眼看到"完整版有 13 个区域的规划"，MVP 体量小反而变成"冰山一角"的展示优势。实现成本极低：一张地图底图 + 13 个按钮热区。

## 4. 系统规格

### 4.1 三值系统（HUD 左上三条）

| 数值 | 上限 | 消耗 | 回复 | 归零后果 |
|---|---|---|---|---|
| 氧气值 | 100 | 草原 0.5/s；矿洞 2/s | 回草原/营地缓慢回满；氧气瓶（电解站灌）+50 | 生命 5/s 持续掉 |
| 能量值 | 100 | 0.3/s | 营地篝火进食 +40；葡萄糖道具 +20 | 移动速度减半 |
| 生命值 | 100 | 见伤害表 | 睡觉回满；营地篝火旁缓慢回复 | 死亡 |

伤害表：CO 幽灵接触 -8/s（戴活性炭口罩免疫）；酸雾怪接触 -10/次；氢气爆炸 -50；CuSO₄ 溶液池浸泡 -5/s（"蓝色溶液：硫酸铜，重金属盐有毒"）。

**每条数值变化配一条化学解释字幕**（如矿洞掉氧加快时：「氧气不足，呼吸加快——为什么矿洞要通风？」）。

### 4.2 昼夜循环

- 演示参数：白天 6 分钟 + 夜晚 3 分钟（常量可调，调参阶段重点）。
- 夜晚：画面 tint 变暗；怪物在营地外围刷新（酸雾怪 ×2~3）；无火把时视野缩到主角周围一圈。
- 床：交互 → 画面渐黑 → 直接跳到第二天清晨，生命回满，资源刷新。

### 4.3 采集与背包

- 采集物漂浮发光，走近按 E 拾取；首次获得某物质弹出 3 秒字幕气泡（名称 + 化学式 + 一句课本性质）。
- 背包：8 格快捷栏 + 背包界面，堆叠上限 99。
- 左上计数「已收集 N/16」。

### 4.4 合成系统

- 营地合成台交互打开合成界面：左侧背包材料拖入 2~3 个合成格，选择器材（酒精灯/实验台/便携合成格），点「反应」。
- 引擎查 recipes.json：材料 + 条件匹配 → 成功，产物入包 + 弹出**知识卡片**（方程式 + 现象 + 现实应用，可跳过）；不匹配 → 失败字幕（如「没有生成沉淀、气体或水，所以不反应」——失败也是教学）。
- 每张卡片底部固定一行：「反应前后原子种类和数目不变——质量守恒定律」。

### 4.5 特殊事件：氢气验纯爆炸（全场核心记忆点，必须做到最好）

1. 玩家在电解器获得 H₂ 后，合成界面出现「点燃」选项。
2. 直接点燃 → 爆炸动画（屏幕震动 + 火光 + 音效）→ 生命 -50 → 巨大字幕：「**氢气不纯点燃会发生爆炸！点燃前必须验纯**——去导师学院问问为什么」。
3. 从导师处得到答案后，合成界面解锁「验纯」步骤（收集一小试管 H₂，靠近火焰听"噗"轻响）→ 验纯后点燃成功，卡片：「2H₂+O₂=点燃=2H₂O，氢能源：最清洁的燃料」。
4. 设计意图：失败变成最想知道答案的瞬间——这是整个产品的灵魂场景，演示时必演。

### 4.6 怪物 ×2（每只怪 = 一道应用题）

| 怪物 | 出现 | 行为 | 对策（知识点） |
|---|---|---|---|
| CO 幽灵（灰色半透明） | 矿洞全天 + 草原夜晚 | 缓慢飘向玩家，接触掉血 | 活性炭口罩（活性炭吸附性——防毒面具原理） |
| 酸雾怪（黄绿色雾团） | 夜晚营地外围 | 直线冲撞 | 中和喷雾喷中即消散（酸碱中和：酸+碱→盐+水） |

### 4.7 死亡与复活

三值任一归零或致命伤害 → 死亡画面（「你倒下了……化学不等人」）→ 营地床铺复活，身上物品掉在死亡地点（发光标记，可跑回捡）。死亡是唯一的"关卡"。

### 4.8 导师学院（像素工作室式：导师小人在房间里 + 底部聊天框）

- 一座建筑四个房间（化学实验室/班主任办公室/自习室/思维工坊），**每个房间里有一位导师像素小人**（32×32，idle 两帧张合/踱步），整体观感参考 OpenClaw 像素工作室：小人站在自己的小房间里各忙各的。
- 四位导师（有名字有性格，完整人设见内容 spec 第 4 节）：化学老师·袁仲衡、班主任·苏婉清、助理·周启明、实用思维老师·曲嫣然。
- 交互：走近任意导师 → 头顶出现「按 E 提问」气泡 → 按 E 后**屏幕底部弹出像素聊天框**（左侧导师半身立绘 + 名称，右侧对话记录 + 输入框），画面不停、不切换场景。立绘双帧：不说话时 `idle`、回答时切 `talk`，配合逐字打字。
- 对话流程（**班主任统一调度机制**，程序约束见内容 spec 4.1）：学生不能 @ 任何老师——不管在哪个房间、输入什么，**统一由班主任苏婉清首接**（"别慌，这件事我来安排"）→ 班主任判断问题类型并 @ 派给对应老师（化学→袁仲衡／战斗→曲嫣然／学法→曲嫣然+周启明／其他→周启明）→ 被派老师的立绘切换进场，逐字回答 → **终止**（只有班主任能 @，其他老师答完即止，最多 2 轮，不会来回乱跳）。
- 联网：调 DeepSeek API（人设由 system prompt 决定，见内容 spec 第 4 节）；断网：班主任内部关键词路由 + 本地兜底问答，回答末尾标注「（离线模式）」。
- 配置面板：MVP 只做 UI 占位（API key 输入框可用；性格滑块显示但不动效），演示时口头讲"赛后可配置"。

### 4.9 图鉴（简版）

主菜单与游戏内均可打开：16 格物质收集网格（未收集为剪影）+ 已解锁反应卡片页（方程式 + 一句话应用）。这是"学习进度可视化"，给家长和评委看的一屏。

### 4.10 字幕引擎

全局 Autoload，一行调用 `KnowledgeTip.show("tip_id")`；全部文案存 tips.json（约 30 条，见内容 spec 第 3 节），改文案不碰代码。三种形态：物品头顶气泡（3 秒）、屏幕下方横幅（4 秒）、红色警示（5 秒，用于危险）。

## 5. 新手引导（前 3 分钟，零 UI 教学）

1. 出生即看到发光 O₂ 光球，走过去碰到 → 叮 + 字幕 → 玩家自己学会"碰光球 = 收集"。
2. 氧气值第一次降到 70 时，HUD 闪烁 + 横幅「氧气在消耗——回到开阔地带或制取氧气」。
3. 走到河边自动字幕提示净水；走到合成台旁自动字幕「把材料放进来，试试化学反应」。
4. 不弹任何"教程窗口"，全部用环境 + 字幕引导。

## 6. 演示路径（评委 10~15 分钟脚本，彩排与视频都按这个走）

| 时间 | 玩家动作 | 展示点 |
|---|---|---|
| 0–2 min | 草原捡 O₂、C，看字幕；横幅光合作用 | 见物即学 |
| 2–4 min | 河边取水 → 过滤器四步字幕 → 电解器得 H₂/O₂；顺路进盐湖捡粗盐、用肥皂水试湖水（若时间紧可跳过盐湖） | 水的净化、电解水、硬水 |
| 4–7 min | 下矿洞：氧气掉快、捡 S/CaCO₃、躲 CO 幽灵（先硬挨一下掉血给观众看） | 氧气分区、CO 毒性 |
| 7–9 min | 回营地合成硫火把（卡片弹出）→ 氢气直接点燃 → **爆炸** | 合成系统、核心记忆点 |
| 9–12 min | 导师学院问"为什么氢气会爆炸"→ **班主任首接并 @化学老师** → 袁仲衡回答；追问"接下来该做什么"→ 班主任 @助理，周启明给出三步计划 | AI 导师团协作（联网演示 + 提一句断网兜底） |
| 12–15 min | 验纯后点燃成功；夜晚到来：火把照明、喷雾打酸雾怪、口罩过幽灵、床睡觉 | 夜晚生存循环 |
| 结尾 | 打开图鉴翻给评委看 | 学习进度可视化 |

## 7. MVP 知识覆盖声明（写在 PPT 里）

MVP 覆盖初中化学 12 单元中的 7 个核心单元：我们周围的空气、自然界的水、碳和碳的氧化物、燃料及其利用、酸和碱、金属和金属材料（部分）、盐 化肥（粗盐提纯/硬水）。完整版设计（12 单元全覆盖 + 技能树 + 颜色鉴别玩法）已完成文档规划——**配合世界地图页的 8 个未解锁区域一起讲，把"没做完"变成"冰山一角"**。
