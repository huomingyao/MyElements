# SPEC-02｜游戏设计规格

> 本文件定义「玩起来是什么样」。范围以 MVP 为准；完整版设想只在 §10 备忘，不在本次实现范围。
> 本文件描述行为，**不描述接口**（接口见 [SPEC-03](SPEC-03-系统与接口契约.md)），**不存文案**（文案见 [SPEC-05](SPEC-05-内容数据表.md)）。

---

## 1. 产品概念

**一句话**：一个 2D 横版像素开放世界，世界规则就是初中化学课本——没有魔法，只有化学。

玩家是一个小炼金术士，在一张持续存在的世界里收集真实物质、用真实反应条件合成道具、靠化学知识活下去（照明、防毒、灭火、打怪），遇到不懂的就去地图中央的「导师学院」问四位 AI 导师。

**三句收束文案**（对外统一口径，视频结尾与 PPT 都用它）：
- 对玩家：这是一个不作弊就玩不下去的游戏——而作弊方式恰好是翻开化学书。
- 对家长：他玩的每一次合成，都是考卷上要写的那条方程式。
- 对评委：我们把初中化学翻译成了游戏机制——知识不是游戏的皮肤，是游戏的物理引擎。

## 2. 核心循环

```
探索收集 → 鉴别/合成 → 用品生存 → 卡关问导师 → 学到知识 → 更深探索
     ↑                                                        │
     └──────── 三值永远下降 + 怪物每晚刷新 = 循环永远转 ────────┘
```

**永续发动机**（区别于剧情 demo 的关键）：
- 唯一失败 = 死亡（床铺复活、掉落可捡回），没有"通关"。
- 玩家目标自定：集齐图鉴 16 种（HUD 计数口径）？挖穿矿洞？提纯粗盐？
- 资源可再生：采集物在每天清晨刷新（FR-C-04 AC4），世界采不空。

## 3. 世界与地图

MVP：4 区 + 1 学院，**一张连续地图，不切场景**（学院可为同图内的建筑内部，用区域触发器区分）。

```
[盐湖]——[矿洞一层]                [导师学院]
           │ 入口在草原右侧         │ 地图中央偏上，安全区
        [草原（出生点）]——[营地]—————┘
        （草原与营地相连，营地是草原的一部分；盐湖在草原左侧，无怪物）
```

| 区域 id | 名称 | 可收集物质 | 环境机制 | 覆盖知识点 |
|---|---|---|---|---|
| `grassland` | 草原（出生） | O₂（光球）、C（木炭）、树木 | 氧气 0.5/s；白天安全，夜晚有 CO 幽灵 | 空气成分、光合作用、物理/化学变化 |
| `camp` | 营地（草原内） | 水（河边取水）、H₂/O₂（电解器） | 固定设施：过滤器、电解器、合成台、篝火、床 | 水的净化四步、电解水、六大营养素 |
| `saltlake` | 盐湖（安全区） | 粗盐、湖水（硬水） | 无怪物、无氧气消耗，纯收集 + 教学区 | 粗盐提纯、硬水与软水、溶解现象 |
| `mine` | 矿洞一层 | S、CaCO₃、CuSO₄（溶液池）、Fe₂O₃ | 氧气 2.0/s（×4）；黑暗需火把；CO 幽灵全天 | 燃烧条件、CO 毒性、矿物成分 |
| `academy` | 导师学院（安全区） | 无 | 四导师常驻；怪物不入内；无消耗 | 全部知识兜底问答 |

**盐湖存在的理由**：机制最简单（无怪物、无数值威胁），铺图成本最低，但让地图从"一条线"变成"有左右探索感"，并顺手覆盖第 11 单元「盐 化肥」的粗盐提纯与硬水考点。

**区域字幕**：走近首次触发一次，文案见 [SPEC-05 §3.1](SPEC-05-内容数据表.md)（`zone_grass/zone_salt/zone_mine/zone_river/zone_camp/zone_academy/zone_photosynthesis`）。

### 3.1 世界地图页（关键展示点）

- 入口：主菜单一个门 + 游戏内按 M / 交互营地路牌。
- 形态：手绘风世界地图底图，**13 个区域全部显示**——
  - 已解锁 5 个：彩色 + 可点击查看简介；
  - 未解锁 8 个：**灰色剪影 + 名称 + 一句预告文案 +「赛后解锁」角标**，点击时抖动一下并显示预告语，不可进入。
- 未解锁区域：深层矿洞、火山口·熔炉高地、金属矿山、酸碱沼泽、水晶矿洞、气之国、生命草原、电解实验室。
- 设计意图：评委打开地图一眼看到"完整版有 13 个区域的规划"，MVP 体量小反而成为"冰山一角"的展示优势。实现成本极低：一张底图 + 13 个按钮热区 + 一张数据表。

完整区域清单与预告文案见 [SPEC-05 §7](SPEC-05-内容数据表.md)。

## 4. 系统规格与参数表

**本节所有数值均落在 `data/balance.json`（FR-D-08），改数值不改代码。** 下表是调参基线，H12–H14 调参阶段以"评委 10 分钟体验到全部环节"为目标微调。

### 4.1 三值系统（HUD 左上三条）

| 数值 | 键名 | 上限 | 消耗 | 回复 | 归零后果 |
|---|---|---|---|---|---|
| 氧气值 | `oxygen` | 100 | 草原/营地 0.5/s；矿洞 2.0/s；盐湖/学院 0 | 回草原/营地缓慢回满（1.0/s）；氧气瓶 +50 | 生命 5/s 持续掉 |
| 能量值 | `energy` | 100 | 0.3/s（全区一致） | 篝火进食 +40；葡萄糖 +20 | 移动速度 ×0.5 |
| 生命值 | `health` | 100 | 见伤害表 | 睡觉回满；篝火旁 1.0/s | 死亡 |

**伤害表**：

| 来源 | 伤害 | 免疫/对策 |
|---|---|---|
| CO 幽灵接触 | 8/s | 活性炭口罩（完全免疫） |
| 酸雾怪冲撞 | 10/次 | 中和喷雾先消灭 |
| 氢气爆炸 | 50（一次性） | 先验纯 |
| CuSO₄ 溶液池浸泡 | 5/s | 别下去（字幕警示） |
| 氧气归零 | 5/s | 回开阔地/氧气瓶 |

**每条数值变化配一条化学解释字幕**：如矿洞掉氧加快时触发 `sys_mine_breath`（"氧气不足时呼吸加快——这就是矿洞要通风的原因"）。

### 4.2 昼夜循环

| 参数 | 键名 | 基线值 |
|---|---|---|
| 白天时长 | `day_duration` | 360 秒（6 分钟） |
| 夜晚时长 | `night_duration` | 180 秒（3 分钟） |
| 夜晚暗度 | `night_tint` | CanvasModulate 到 0.35 亮度 |
| 无光源视野半径 | `dark_view_radius` | 80 px |
| 持火把视野半径 | `torch_view_radius` | 220 px |

夜晚行为：画面 tint 变暗；酸雾怪在营地外围刷新 2~3 只；无火把时视野收缩到主角周围一圈。
床交互：画面渐黑 → 直接跳到第二天清晨 → 生命回满 → 采集物刷新 → `day_count` +1。

### 4.3 采集与背包

- 采集物漂浮 + 发光呼吸动画；走近按 E 拾取。
- 首次获得某物质弹出 3 秒 `bubble` 字幕（名称 + 化学式 + 一句课本性质）。
- 背包：8 格快捷栏 + 背包界面（Tab），堆叠上限 99。
- HUD 左上显示「已收集 N/16」。
- 采集物**不需要工具**（MVP 砍掉工具分层），走近即可拾取。

### 4.4 合成系统

1. 营地合成台交互 → 打开合成界面。
2. 从背包拖入 2~3 个材料到合成格；选择器材：`portable`（便携格）/ `alcohol_lamp`（酒精灯）/ `bench`（实验台）。
3. 点「反应」→ 引擎查 `recipes.json`：
   - **材料 + 器材 + 条件全部匹配** → 成功：产物入包 + 弹出**知识卡片**（标题 + 方程式 + 现象 + 现实应用，可跳过）。
   - **材料对但条件/器材不对** → 失败：条件类文案（"条件不够——有些反应需要点燃、加热、通电或催化剂"）。
   - **完全不匹配** → 失败：轮换文案（"没有新物质生成——这只是物理混合，不是化学反应" / "没有生成沉淀、气体或水，所以不反应"）。
4. 失败**不消耗材料**（20 小时版本对玩家友好，避免评委卡死）。
5. 每张卡片底部固定一行 `card_footer`：「反应前后原子种类和数目不变——质量守恒定律」。

11 条配方的完整内容见 [SPEC-05 §2](SPEC-05-内容数据表.md)。

### 4.5 特殊事件：氢气验纯爆炸（全场核心记忆点）

**这是整个产品的灵魂场景，演示必演，优先级高于一切美术打磨。**

流程状态机：

```
获得 H₂ ──► 合成界面出现「点燃」
              │
              ├─ purity_check_unlocked == false ─► 直接点燃
              │      └─► 爆炸动画（屏幕震动+火光+音效）
              │            └─► 生命 -50
              │                  └─► warning 字幕 sys_explosion_warn
              │                        └─► 设 explosion_happened = true
              │
              └─ purity_check_unlocked == true ──► 出现「验纯」步骤
                     └─► 验纯（"噗"轻响 + sys_purity_ok）
                           └─► 点燃成功
                                 └─► 卡片：2H₂+O₂=点燃=2H₂O，氢能源
```

`purity_check_unlocked` 的解锁条件：向导师提问过氢气/爆炸/验纯相关问题（由导师模块回调设置）。另有演示保险开关可强制解锁（FR-G-09 AC4）。

设计意图：**失败变成最想知道答案的瞬间**——玩家被炸一次后主动跑去问导师，这就是"知识作为游戏机制"的证明。

### 4.6 怪物 ×2（每只怪 = 一道应用题）

| 怪物 | 出现条件 | 行为 | 对策（知识点） |
|---|---|---|---|
| CO 幽灵（灰色半透明） | 矿洞全天 + 草原夜晚 | 缓慢飘向玩家，接触掉血 8/s | 活性炭口罩（活性炭吸附性——防毒面具原理） |
| 酸雾怪（黄绿色雾团） | 夜晚营地外围，2~3 只 | 直线冲撞，命中 -10 | 中和喷雾喷中即消散（酸+碱→盐+水） |

怪物 AI 保持最简：CO 幽灵为匀速追踪（可穿墙，符合"气体"设定）；酸雾怪为锁定方向直线冲撞 + 撞墙后重新锁定。**不做寻路，不做状态机分层。**

### 4.7 死亡与复活

三值任一归零或受到致命伤害 → 死亡画面（字幕 `sys_death`：「你倒下了……化学不等人」）→ 营地床铺复活，三值回满，身上物品掉在死亡地点（发光标记，可跑回捡）。**死亡是唯一的"关卡"。**

### 4.8 导师学院（像素工作室式）

- 一座建筑四个房间：化学实验室 / 班主任办公室 / 自习室 / 思维工坊。**每个房间里有一位导师像素小人**（32×32，idle 两帧张合或踱步），整体观感参考像素工作室：小人站在自己的小房间里各忙各的。
- 四位导师（完整人设见 [SPEC-05 §4](SPEC-05-内容数据表.md)）：
  - 化学老师·袁仲衡（`chem`）— 化学实验室
  - 班主任·苏婉清（`monitor`）— 班主任办公室 — **调度中心**
  - 助理·周启明（`assistant`）— 自习室
  - 实用思维老师·曲嫣然（`think`）— 思维工坊
- 交互：走近任意导师 → 头顶「按 E 提问」气泡 → 按 E → **屏幕底部弹出像素聊天框**（左侧导师半身立绘 + 名称，右侧对话记录 + 输入框）。**画面不停、不切换场景。** 立绘双帧：不说话 `idle`，回答时切 `talk`，配合逐字打字。
- **对话流程（班主任统一调度机制，程序必须严格实现）**：

```
玩家输入（不能 @ 任何人）
   │
   ▼
班主任 苏婉清 首接（不论玩家站在哪个房间）
   │  "别慌，这件事我来安排" + 一句带 @ 的调度语
   ▼
分类判断
   ├─ 战斗/危险类 ────► @思维老师
   ├─ 学习方法类 ────► @思维老师 + @助理
   ├─ 化学知识类 ────► @化学老师
   └─ 其他/目标 ─────► @助理
   │
   ▼
被派老师回答（回复中禁止出现 @）
   │
   ▼
终止（最多 2 轮，班主任调度最多 1 次，不会死循环）
```

- 联网：调 DeepSeek API，人设由 system prompt 决定。断网：班主任内部关键词路由 + 本地兜底问答，回答末尾标注「（离线模式）」。
- 配置面板：MVP 只做 UI 占位（API key 输入框可用；性格滑块显示但不生效），演示时口头讲"赛后可配置"。

调度分类表与协作链示例见 [SPEC-05 §4.1](SPEC-05-内容数据表.md)；实现约束见 [SPEC-03 §6](SPEC-03-系统与接口契约.md)。

### 4.9 图鉴（简版）

主菜单与游戏内均可打开：
- 16 格物质收集网格（未收集为剪影，不泄露名称）；已收集显示彩色图标 + 分类标签（单质/化合物/氧化物/酸/碱/盐）。

这是"学习进度可视化"，给家长和评委看的一屏。

### 4.10 字幕引擎

全局 Autoload，一行调用 `KnowledgeTip.show("tip_id")`；全部文案存 `tips.json`（47 条，见 [SPEC-05 §3](SPEC-05-内容数据表.md)），改文案不碰代码。三种形态：

| style | 位置 | 时长 | 用途 |
|---|---|---|---|
| `bubble` | 物品/玩家头顶 | 3 秒 | 首次拾取物质 |
| `banner` | 屏幕下方横幅 | 4 秒 | 区域进入、机制提示 |
| `warning` | 屏幕中部红字 | 5 秒 | 危险与爆炸 |

多条同时触发时排队显示，不重叠。标记为"首次触发"的字幕重复调用不再显示。

## 6. 新手引导（前 3 分钟，零 UI 教学）

1. 出生即看到发光 O₂ 光球，走过去碰到 → 叮 + 字幕 → 玩家自己学会"碰光球 = 收集"。
2. 氧气值第一次降到 70 时，HUD 闪烁 + 横幅「氧气在消耗——回到开阔地带或制取氧气」。
3. 走到河边自动字幕提示净水；走到合成台旁自动字幕「把材料放进来，试试化学反应」。
4. **不弹任何"教程窗口"**，全部用环境 + 字幕引导。

## 7. 演示路径（评委 10~15 分钟脚本）

彩排与视频都按这个走。

| 时间 | 玩家动作 | 展示点 |
|---|---|---|
| 0–2 min | 草原捡 O₂、C，看字幕；横幅光合作用 | 见物即学 |
| 2–4 min | 河边取水 → 过滤器四步字幕 → 电解器得 H₂/O₂；顺路进盐湖捡粗盐、用肥皂水试湖水（时间紧可跳过盐湖） | 水的净化、电解水、硬水 |
| 4–7 min | 下矿洞：氧气掉快、捡 S/CaCO₃、躲 CO 幽灵（先硬挨一下掉血给观众看） | 氧气分区、CO 毒性 |
| 7–9 min | 回营地合成硫火把（卡片弹出）→ 氢气直接点燃 → **爆炸** | 合成系统、核心记忆点 |
| 9–12 min | 导师学院问"为什么氢气会爆炸"→ **班主任首接并 @化学老师** → 袁仲衡回答；追问"接下来该做什么"→ 班主任 @助理，周启明给出三步计划 | AI 导师团协作（联网演示 + 提一句断网兜底） |
| 12–15 min | 验纯后点燃成功；夜晚到来：火把照明、喷雾打酸雾怪、口罩过幽灵、床睡觉 | 夜晚生存循环 |
| 结尾 | 打开图鉴翻给评委看 | 学习进度可视化 |

**调参目标**：昼夜时长与消耗速率必须保证评委在 10~15 分钟内自然经历"白天采集 → 夜晚生存 → 睡觉"完整周期。

## 9. MVP 知识覆盖声明（写进 PPT）

MVP 覆盖初中化学 12 单元中的 **7 个核心单元**：
我们周围的空气 · 自然界的水 · 碳和碳的氧化物 · 燃料及其利用 · 酸和碱 · 金属和金属材料（部分）· 盐 化肥（粗盐提纯/硬水）。
