# SPEC-01｜需求与验收标准

> 本文件是全部功能需求（FR）与验收标准（AC）的唯一来源。
> **开工前**：确认你要做的事有 FR 条目；没有就先在这里加，再动手。
> **AC 写法约束**：每条 AC 必须能被一个测试或一次可复现的手工步骤判定真假，不许写"体验流畅""效果好"。

条目格式：

```
### FR-X-NN 标题
`优先级` · 责任人 · 依赖 · 测试用例
描述（一到两句，说清边界）
- **AC1** 可判定的验收条件
```

优先级定义：
- `P0` — 缺了就没有闭环，演示直接失败。任何情况下不许砍。
- `P1` — 影响演示完整度，可降级实现（美术用占位、参数写死）。
- `P2` — 加分项，H12 前做不完直接砍进赛后清单，不讨论。

## 1. 目标与成功判据

20 小时后交付两样东西：

1. **Windows 可玩 demo** — 评委上手玩 10~15 分钟，完整闭环，**断网可玩**；
2. **3 分钟演示视频** — 防现场设备翻车的备份，同时是评分材料。

成功判据 = [SPEC.md](SPEC.md) Phase Checklist 全部 `[x]` + 本文件 §11 手工验收清单全部打勾。

## 2. 范围边界

### 2.1 做（MVP）

三值系统 · 昼夜循环 · 采集与背包（17 种物质，HUD 计 16）· 盐湖安全收集区 · 世界地图页（13 区域，8 个灰色剪影）· 合成台 + 11 条配方 + 知识卡片 · **氢气不验纯爆炸事件** · 怪物 ×2（CO 幽灵、酸雾怪）· 导师学院（4 位具名 AI 导师 + 班主任统一调度 + LLM 与本地兜底）· 图鉴简版 · 死亡复活与掉落可捡回 · 字幕引擎（47 条）· 主菜单三个门。

### 2.2 不做（赛后清单，谁提谁记录，不讨论）

自由建造/放置方块 · 存档读档 · 未解锁区域的内部场景 · 区域间传送 · 铁锈虫（第 3 种怪）· 导师性格滑块实装（UI 占位可做）· 化肥农田 · 溶解度曲线 · 配平校验玩法 · 技能树 UI · 联机 · 原创音乐 · 多语言 · 手柄支持。

完整赛后清单见 [SPEC-07 §6](SPEC-07-实施计划与Agent派活.md)。

### 2.3 范围变更流程

任何"要不加个 XX" → 记进 SPEC-07 §6 停车场 → 由 P1 裁决 → 若确认加入，必须先在本文件补 FR + AC + 测试编号，再开工。**H12 之后一律拒绝。**

## 3. 核心系统需求（FR-C-*，P1 主责）

### FR-C-01 项目基础配置
`P0` · P1 · 无 · IT-C01
视口 640×360、整数倍缩放、Forward+ 渲染、输入映射（WASD/E/Tab/M/Esc）、主场景入口固定。
- **AC1** `project.godot` 中视口为 640×360，`stretch_mode=canvas_items`，`stretch_aspect=keep`。
- **AC2** 输入动作 `move_left/move_right/jump/interact/inventory/worldmap/pause` 全部已定义且可被 `InputMap.has_action()` 断言。
- **AC3** 从主场景启动无 script error、无缺失资源报错（日志零 ERROR）。

### FR-C-02 三值系统
`P0` · P1 · FR-C-01 · UT-C02
氧气/能量/生命三条数值，按 [SPEC-02 §4.1](SPEC-02-游戏设计.md) 的速率消耗与回复，归零触发对应后果。
- **AC1** 三值上限均为 100，初始值为 100，可被单元测试直接读写。
- **AC2** 每种数值变化发出对应信号（`oxygen_changed/energy_changed/health_changed`），参数为 `(current: float, max: float)`。
- **AC3** 氧气归零后生命按 5/s 持续下降；能量归零后移动速度倍率变为 0.5；生命归零触发 `player_died` 信号。
- **AC4** 全部速率读自 `GameManager` 顶部常量区或 `data/balance.json`，无散落魔法数字（可用 grep 断言逻辑代码中不含裸数值）。

### FR-C-03 区域判定与分区消耗
`P0` · P1 · FR-C-02 · UT-C03
玩家所在区域决定氧气消耗速率与环境效果；区域 id 为 `grassland/camp/saltlake/mine/academy`。
- **AC1** `GameManager.current_zone()` 返回当前区域 id；玩家进出区域触发 `zone_changed(zone_id)`。
- **AC2** 草原/营地氧气 0.5/s，矿洞 2.0/s（×4），盐湖与学院为 0（不消耗）。
- **AC3** 首次进入某区域触发一次该区域横幅字幕（见 [SPEC-05 §3.1](SPEC-05-内容数据表.md)），重复进入不再触发。

### FR-C-04 昼夜循环
`P0` · P1 · FR-C-01 · UT-C04
白天 6 分钟 + 夜晚 3 分钟循环，参数可调；夜晚画面变暗、怪物刷新、无光源时视野收缩。
- **AC1** `GameManager.is_night()` 在时间推进后按参数正确翻转；`day_started/night_started` 信号各触发一次。
- **AC2** 白天/夜晚时长读自 `data/balance.json`，改数值不需改代码。
- **AC3** 夜晚 CanvasModulate 变暗，白天恢复；无火把时玩家周围可视半径收缩到设定值。
- **AC4** 天数计数 `GameManager.day_count` 每次清晨 +1，清晨触发 `resources_respawned` 信号。

### FR-C-05 睡觉跳夜
`P0` · P1 · FR-C-04 · IT-C05
床交互 → 画面渐黑 → 跳到次日清晨，生命回满，资源刷新。
- **AC1** 夜晚在床上交互后 `is_night()` 变 false 且 `day_count` +1。
- **AC2** 生命回到上限；触发字幕 `sys_sleep`。
- **AC3** 采集物在清晨全部重新可拾取（世界采不空）。

### FR-C-06 死亡、复活与掉落
`P0` · P1 · FR-C-02 · IT-C06
生命归零 → 死亡画面 → 营地床铺复活；背包物品掉在死亡点，带发光标记，可跑回捡回。
- **AC1** 生命归零弹出死亡画面并显示字幕 `sys_death`。
- **AC2** 复活后玩家位置为营地床坐标，三值回满，背包为空。
- **AC3** 死亡点生成掉落包，包含死亡瞬间背包全部物品，拾取后物品原数量回到背包。
- **AC4** 掉落包在下一次死亡前不消失。

### FR-C-07 HUD
`P0` · P1 · FR-C-02 · IT-C07
左上三条数值条 + 已收集计数 + 当前时间/天数指示。
- **AC1** 三条数值条实时跟随信号变化，无轮询 `_process` 里的 `get` 硬读。
- **AC2** 显示「已收集 N/16」，N 随首次获得新物质递增。
- **AC3** 氧气低于 30 时数值条闪烁并触发一次 `sys_oxygen_low` 字幕。

### FR-C-08 主菜单三个门
`P0` · P1 · FR-C-01 · IT-C08
开始冒险 / 导师学院 / 图鉴 三个入口 + 退出。
- **AC1** 三个入口分别正确加载世界场景、导师学院场景、图鉴界面。
- **AC2** Esc 在游戏内打开暂停菜单，可返回主菜单。
- **AC3** 从主菜单到世界场景加载耗时在演示机上不超过 3 秒。

### FR-C-09 Autoload 骨架与接口冻结
`P0` · P1 · FR-C-01 · UT-C09
五个 autoload（`GameManager/KnowledgeTip/RecipeDB/LLMClient/WorldMap`）按 [SPEC-03](SPEC-03-系统与接口契约.md) 的签名建立，H1 后接口冻结。
- **AC1** 五个 autoload 均已注册且可在任意场景访问。
- **AC2** SPEC-03 中列出的每个公开方法都存在，签名一致（可用反射断言方法名与参数数量）。
- **AC3** 骨架阶段方法可返回占位值，但不得抛异常，调用方能正常运行。

## 4. 玩家需求（FR-P-*，P1 主责）

### FR-P-01 玩家控制器
`P0` · P1 · FR-C-01 · IT-P01
横版移动、跳跃、重力、朝向翻转；速度受能量状态影响。

### FR-P-03 相机与照明

## 5. 玩法需求（FR-G-*，P2 主责）

### FR-G-01 采集物
`P0` · P2 · FR-P-02、FR-D-01 · IT-G01
场景中漂浮发光的采集物，走近按 E 拾取；类型由 `substances.json` 驱动。
- **AC1** 采集物节点只配置 `substance_id`，名称/图标/字幕全部从数据表读取。
- **AC2** 拾取后物品进背包，采集物消失，播放拾取音效。
- **AC3** 首次获得某物质弹出 3 秒气泡字幕（名称 + 化学式 + 课本性质）。
- **AC4** 数据表中不存在的 id 不崩溃，输出可读错误日志。

### FR-G-02 背包
`P0` · P2 · FR-D-01 · UT-G02
8 格快捷栏 + 背包界面，堆叠上限 99。
- **AC1** `add_item(id, count)` 正确堆叠，超过 99 溢出到新格。
- **AC2** 背包满时 `add_item` 返回未装入的数量，不静默丢弃。
- **AC3** `remove_item(id, count)` 数量不足时返回 false 且不改变状态。
- **AC4** Tab 打开/关闭背包界面，显示图标与数量。

### FR-G-03 首次收集统计
`P1` · P2 · FR-G-02 · UT-G03
记录已发现物质集合，供 HUD 计数与图鉴使用。
- **AC1** 同一物质重复拾取只计一次。
- **AC2** 集合可被图鉴查询（`is_discovered(id)`）。

### FR-G-04 配方引擎
`P0` · P2 · FR-D-02 · UT-G04
读 `recipes.json`，按材料 + 器材 + 条件匹配配方。
- **AC1** `RecipeDB.try_craft(items, tool, condition)` 返回 `{success, recipe_id, outputs, card, fail_tip_id}`。
- **AC2** 材料顺序不影响匹配结果。
- **AC3** 材料正确但器材/条件不符时返回失败并给出条件类失败文案。
- **AC4** 无任何配方匹配时返回失败并轮换 [SPEC-05 §2](SPEC-05-内容数据表.md) 的失败反馈文案。
- **AC5** 11 条配方逐条有单测覆盖（正例 + 至少一个反例）。

### FR-G-05 合成台交互
`P0` · P2 · FR-G-04 · IT-G05
营地合成台打开合成界面：材料拖入 2~3 格 + 选择器材 + 点「反应」。
- **AC1** 界面能从背包拖入材料，取消时材料回到背包（不丢失）。
- **AC2** 成功时产物入背包并弹出知识卡片；失败时显示失败字幕，材料不消耗。
- **AC3** 器材选项为 `portable/alcohol_lamp/bench`（便携格/酒精灯/实验台）。

### FR-G-06 知识卡片弹窗
`P0` · P2 · FR-G-04 · IT-G06
合成成功弹出卡片：标题 + 方程式 + 现象 + 现实应用 + 固定底行。
- **AC1** 卡片全部文字来自 `recipes.json` 字段，无硬编码。
- **AC2** 底部固定显示 `card_footer`（质量守恒定律）。
- **AC3** 可按任意键跳过；跳过后卡片进入图鉴已解锁列表。

### FR-G-07 失败反馈
`P1` · P2 · FR-G-04 · UT-G07
失败也是教学：按失败原因给不同文案。
- **AC1** 三类失败（物理混合 / 无沉淀气体水 / 条件不足）各有独立文案，不混用。
- **AC2** 连续两次同类失败不显示完全相同的文案（轮换）。

### FR-G-08 氢气爆炸事件
`P0` · P2 · FR-G-04、FR-C-02 · IT-G08
**全场核心记忆点。** 未验纯直接点燃 H₂ → 爆炸动画 + 生命 -50 + 警示字幕引导去导师学院。
- **AC1** 获得 H₂ 后合成界面出现「点燃」选项。
- **AC2** 未完成验纯就点燃：播放爆炸动画（屏幕震动 + 火光 + 音效），生命精确 -50，显示 `sys_explosion_warn` 警示字幕（5 秒）。
- **AC3** 爆炸后设置全局标记 `explosion_happened = true`（供导师提示与验纯解锁使用）。
- **AC4** 生命不足 50 时爆炸导致死亡，走 FR-C-06 流程且不卡死。

### FR-G-09 验纯解锁与成功点燃
`P0` · P2 · FR-G-08、FR-M-04 · IT-G09
从导师处得到答案后解锁「验纯」步骤；验纯后点燃成功。
- **AC1** 向导师问过氢气爆炸相关问题后，合成界面出现「验纯」步骤（`purity_check_unlocked = true`）。
- **AC2** 执行验纯播放"噗"轻响并显示 `sys_purity_ok`。
- **AC3** 验纯后点燃成功：产物入包，卡片显示 `2H₂+O₂=点燃=2H₂O` 与氢能源应用，不再扣血。
- **AC4** 未问导师也可通过参数强制解锁（演示保险开关），该开关不影响正常流程。

### FR-G-10 CO 幽灵
`P0` · P2 · FR-C-04 · IT-G10
灰色半透明，矿洞全天 + 草原夜晚出现，缓慢飘向玩家，接触掉血；戴活性炭口罩免疫。
- **AC1** 生成条件正确：矿洞任意时间、草原仅夜晚。
- **AC2** 接触玩家时生命按 8/s 下降；装备活性炭口罩时伤害为 0。
- **AC3** 首次接近时触发一次 `warn_co` 警示字幕。

### FR-G-11 酸雾怪
`P0` · P2 · FR-C-04 · IT-G11
黄绿色雾团，夜晚在营地外围刷新 2~3 只，直线冲撞；中和喷雾喷中即消散。
- **AC1** 仅夜晚刷新，数量在 2~3 之间，白天清除。
- **AC2** 冲撞命中玩家生命 -10（单次）。
- **AC3** 中和喷雾命中即销毁并显示 `sys_spray` 字幕。

### FR-G-12 道具生效
`P0` · P2 · FR-G-02 · UT-G12
中和喷雾、活性炭口罩、灭火器、硫火把、氧气瓶、葡萄糖按各自效果生效。
- **AC1** 每个道具的效果值读自数据表，改数值不改代码。
- **AC2** 口罩为装备型（持续免疫 CO），喷雾/灭火器为消耗型（使用后数量 -1）。
- **AC3** 氧气瓶 +50 氧气，葡萄糖 +20 能量，硫火把提供照明（FR-P-03）。

### FR-G-13 营地设施
`P0` · P2 · FR-P-02 · IT-G13
过滤器、电解器、篝火、床、合成台五个固定设施。
- **AC1** 过滤器交互：水 → 纯净水，触发净水四步字幕 `sys_filter`。
- **AC2** 电解器交互：纯净水 → H₂ + O₂，触发 `sys_electrolysis` 并按体积比 1:2 给量。
- **AC3** 篝火交互：进食 +40 能量，旁边生命缓慢回复。
- **AC4** 床交互走 FR-C-05。

### FR-G-14 粗盐提纯三步
`P1` · P2 · FR-G-05 · IT-G14
实验台三步流程：溶解 → 过滤 → 蒸发，得到 NaCl，每步一条字幕。
- **AC1** 三步必须按顺序完成，跳步时给提示不给产物。
- **AC2** 完成后获得 `nacl`，弹出卡片说明这是物理变化（无新物质生成）。
- **AC3** 对湖水使用肥皂水显示 `sys_hardwater`。

## 6. 导师需求（FR-M-*，P3 主责）

### FR-M-01 导师学院场景
`P0` · P3 · FR-C-01 · IT-M01
一座建筑四个房间（化学实验室/班主任办公室/自习室/思维工坊），每间有一位导师像素小人（32×32，idle 两帧）。
- **AC1** 四个房间各有一位导师，位置与 `mentors.json` 的 `room` 字段一致。
- **AC2** 学院内不消耗氧气、怪物不进入。
- **AC3** 走近导师头顶出现「按 E 提问」气泡。

### FR-M-02 底部聊天框 UI
`P0` · P3 · FR-M-01 · IT-M02
按 E 后屏幕底部弹出聊天框：左侧导师半身立绘 + 名称，右侧对话记录 + 输入框；画面不停、不切场景。
- **AC1** 聊天框打开时游戏世界不暂停、不切换场景。
- **AC2** 回答逐字打字显示；打字期间立绘为 `talk`，结束切回 `idle`。
- **AC3** 对话记录可滚动，保留本次会话全部消息。
- **AC4** Esc 或关闭按钮收起聊天框，玩家恢复操作。

### FR-M-03 输入清理
`P0` · P3 · FR-M-02 · UT-M03
玩家输入在进入 prompt 前做长度截断与字符清理。
- **AC1** 输入超过 200 字符被截断。
- **AC2** 控制字符与换行被清理；空输入不发起请求。
- **AC3** 输入内容不参与任何代码执行路径（只作为文本）。

### FR-M-04 班主任统一调度
`P0` · P3 · FR-D-04 · UT-M04
**核心机制。** 学生不能 @ 任何老师；任何输入统一由班主任（`monitor`）首接，班主任判断类型并 @ 派给对应老师。
- **AC1** 不论玩家站在哪个房间、输入什么，第一条回复都来自 `monitor`。
- **AC2** 班主任回复格式为「一句安抚 + 一句带 @ 的调度语」。

### FR-M-05 @ 解析与终止约束
