# SPEC-08｜美术与音频管线

> 本文件管"看起来/听起来是什么样，以及资产怎么进仓库"。P4 主责，P5 协助切片与音频。
> 铁律：**风格统一 > 单张精美**。一张好看但跑调的图，不如五张一致的普通图。

---

## 1. 视觉基调与硬规格

- 风格：16-bit 像素、侧视 2D 平台。整体明亮、童书感（面向初中生与家长），只有矿洞压暗。
- 参考感觉（不抄具体资产）：整体亮度接近 Terraria 地表，色感偏星露谷的暖调。
- 唯一光源逻辑：白天全亮；夜晚整体压暗到 `daynight.night_brightness`（0.35），火把开一圈可见半径。

| 项 | 规格 | 说明 |
|---|---|---|
| 视口 | 640×360 | 整数缩放（`canvas_items` + `keep`），见 [SPEC-01 FR-C-01](SPEC-01-需求与验收.md) |
| 物品/图标 | 16×16 | 背包、快捷栏、图鉴共用一套 |
| 角色/怪物 | 32×32 | 玩家、CO 幽灵、酸雾怪、导师像素小人 |
| Tile | 16×16 | TileSet 网格必须严格对齐 |
| 导师立绘 | 240×320（上限 256×384） | 半身，聊天框左侧显示 |
| 特效帧 | 64×64 | 爆炸、喷雾、验纯气泡 |
| 缩放 | 只允许整数倍 | 禁止 filter、禁止 mipmap |

**禁止**：抗锯齿边缘、半透明羽化、非整数缩放、混入矢量风 UI 图标。

## 3. 目录与命名

```
assets/
├── art/
│   ├── icons/          # 16×16 物质与道具图标，文件名 = 数据表 id
│   ├── tiles/          # TileSet 源图（按区域分文件）
│   ├── chars/          # 32×32 玩家与怪物 spritesheet
│   ├── mentors/        # 立绘 + 像素小人
│   ├── ui/             # 面板、按钮、卡片底、地图页底图
│   ├── fx/             # 64×64 特效帧
│   └── placeholder.png # 占位图（缺资源时数据表指向这里）
└── audio/
    ├── sfx/
    └── bgm/
```

命名规则（**校验器会按 id 拼路径，写错就报缺失**）：

| 类型 | 规则 | 例 |
|---|---|---|
| 物质图标 | `icons/<substance_id>.png` | `icons/h2o_clean.png` |
| 道具图标 | `icons/<item_id>.png` | `icons/sulfur_torch.png` |
| 导师立绘 | `mentors/<mentor_id>_idle.png` / `_talk.png` | `mentors/chem_talk.png` |
| 导师小人 | `mentors/<mentor_id>_pixel.png` | `mentors/monitor_pixel.png` |
| 角色表 | `chars/<name>_sheet.png` | `chars/player_sheet.png` |
| 特效 | `fx/<effect>_<帧数>f.png` | `fx/explosion_6f.png` |
| 音效 | `sfx/<动作>.ogg` | `sfx/craft_success.ogg` |

全小写蛇形，禁止空格、中文、大写。所有路径在数据表里写 `res://` 绝对路径。

## 4. 生成流程与第一批提示词

网页生成要排队，**H0 第一件事就是把第一批提交出去**，别等到需要时才生成。

### 4.1 流程

1. 写提示词（中文即可）→ 生成 → 下载 PNG。
2. 降色到 §2 调色板（Aseprite 或 GIMP 的 index 模式，目标 32 色，dither 关掉）。
3. 缩放到目标像素尺寸，**只用 nearest**。
4. 按 §3 命名放进目录。
5. Godot 导入设置：`Filter = Off`、`Mipmaps = Off`、`Fix Alpha Border = On`。
6. 进游戏截一张图确认与周围资产不跑调（P4 终审）。

**验收**：任意两张资产并排看，色感不打架；不一致就压调色板重导，不靠"再生成一张碰运气"。

### 4.3 免费素材兜底

生成不理想就直接用免费素材包，**别在一张图上耗超过 20 分钟**。

- Kenney（CC0）：UI、图标、音效——首选，授权最干净
- OpenGameArt（筛 CC0 / CC-BY）：tileset、角色
- itch.io 免费像素包（读清授权）

**授权登记（强制）**：每引入一个外部素材包，在 `assets/CREDITS.md` 追加一行「包名 / 作者 / 授权 / 来源链接 / 用在哪」。CC-BY 的必须在游戏内 `README.txt` 与 PPT 末页署名。授权不明的**一律不用**。

## 5. 音频

| 用途 | 内容 | 来源 |
|---|---|---|
| BGM ×3 | 白天（轻快）、夜晚（低沉紧张）、学院（温暖） | 免费循环片段，各 30~60 秒循环 |
| 关键音效 | 采集、合成成功、合成失败、**爆炸**、验纯"噗"、受伤、死亡、翻页、打字滴答 | Kenney / freesound（CC0） |

规格：`.ogg`，44.1kHz；音效峰值统一到 -6dB 左右，别一个炸耳一个听不见。**爆炸音是演示高潮**，单独调，要有低频。
Bus：`Master / BGM / SFX` 三条，BGM 默认 -8dB。音频缺失时静默处理，不许因为找不到文件抛错。
