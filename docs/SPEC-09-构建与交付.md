## 5. PPT 与讲稿（P3，H16–H18）

页序：封面 → 痛点（化学靠背，学完不会用）→ 我们的解法（玩中学 + 导师团）→ 核心机制演示（爆炸事件截图）→ 技术架构（Autoload + 数据驱动 + LLM 调度链）→ **开发方法（SSD + TDD + 多 Agent 协作，附追溯矩阵截图）** → 教育价值（覆盖 7 单元考点，图鉴 17 物质 11 反应）→ 可扩展性（13 区域，8 个待解锁；架构可换知识领域）→ 团队分工 → 致谢与素材署名。

讲稿要求：控制在 3 分钟口播；每页一句主张；**准备两条应急话术**——「现场断网 → 离线模式也能答」「遇到 bug → 这条已在台账，绕行演示」。
