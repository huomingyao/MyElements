# 元素炼金物语（网页版）

一个 2D 横版像素开放世界，世界规则就是初中化学课本——没有魔法，只有化学。
草原收集 → 营地合成 → 氢气爆炸 → 导师问答 → 夜晚生存 → 睡觉复活，10~15 分钟闭环。

## 运行

```bash
npm install        # 安装依赖
npm run assets     # （可选）重新处理素材：切图/图标/拷贝音乐
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 构建静态产物 dist/
npm run preview    # 本地预览构建产物
```

部署：把 `dist/` 整个目录放到任意静态服务器（GitHub Pages / itch.io / Nginx）即可，无服务端依赖。

## 玩法路径（10~15 分钟）

1. 草原捡 O₂、C、木棒（头顶知识字幕，图鉴点亮）
2. 盐湖捡粗盐、肥皂水试湖水（硬水）；回营地实验台做粗盐三步提纯得 NaCl
3. 营地河边取水 → 过滤器（净水四步）→ 电解器（得 H₂/O₂ + 氧气瓶）
4. 矿洞采 S/CaCO₃/Fe/Fe₂O₃（氧气加速消耗、CO 幽灵、CuSO₄ 溶液池别泡）
5. 合成台：木棒+硫 → 硫火把（知识卡片）
6. H₂+O₂ 未验纯点燃 → **爆炸 -50** → 去导师学院问"为什么氢气会爆炸"（班主任苏婉清首接并 @化学老师）→ 解锁验纯 → 验纯后点燃成功
7. 夜晚：火把照明、中和喷雾打酸雾怪、活性炭砸 CO 幽灵（口罩免疫）
8. 床睡觉跳夜（资源刷新）；死亡掉落在死亡点可捡回，床复活
9. 原住民收购装备换能量（+20）

## 导师联网

默认离线模式，全流程可完整体验，回答带「（离线模式）」标记（34 条本地兜底问答 + 班主任调度链）。
在聊天框「设置」里填入 DeepSeek API key 后导师走在线回答（key 只存在你自己的浏览器 localStorage，不进任何文件与日志）。

## 技术栈

TypeScript + Phaser 3（世界渲染）+ DOM UI（面板）+ Vite。数据驱动：全部文案与数值在 `data/*.json`（10 张表），改内容不改代码。
